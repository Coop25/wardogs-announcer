# WARDOGS Pilot Announcement Generator

A local, offline, single-page app that displays a rotating stream of
pilot/passenger announcements — built to sit on a second monitor while
you fly transport missions in WARDOGS.

**Content is just a plain text file.** One announcement per line in
[`data/announcements.txt`](data/announcements.txt). No templates, no
placeholders, no procedural assembly — the app picks a random line,
avoids repeating recent ones, and displays it. Whatever you write is
exactly what shows up.

## Running it

Just double-click [`index.html`](index.html). Everything needed to run is
already in this folder, including a pre-built `data/bundle.js` (see
"Why bundle.js exists" below). No server, no install, no internet
connection required.

## Editing the announcement list

Open [`data/announcements.txt`](data/announcements.txt) and add, remove,
or edit lines — one complete announcement per line, blank lines are
ignored, duplicate lines are skipped with a console warning. That's the
entire content format.

After editing, rebuild the bundle so `file://` mode picks up the change:

```bash
node build.js
```

or, if you don't have Node installed (Windows-native option, no installs
required):

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Either one just regenerates `data/bundle.js` from `announcements.txt` —
never required to run the finished app itself, only to pick up edits. You
can also skip the build step entirely by running the app via a local
static server instead — see below — which loads `announcements.txt`
directly.

## Architecture

```
index.html
css/
  styles.css
js/
  lines.js     - loads announcements.txt (or bundle.js), non-repeating
                 random picker
  history.js    - localStorage-backed anti-repeat ring buffer
  app.js        - UI: timer, buttons, settings panel, status bar, share
                 links, team picker
data/
  announcements.txt  - THE content file: one announcement per line
  bundle.js            - AUTO-GENERATED by build.js/build.ps1; lets
                         index.html work via file:// (see below)
build.js              - optional dev-only script: node build.js regenerates
                       data/bundle.js from announcements.txt
build.ps1              - same thing, no Node required (Windows PowerShell)
dev-server.ps1          - optional tiny local static file server, no
                       installs required, alternative to the bundle
```

### Why `bundle.js` exists

Browsers block `fetch()` of local files when a page is opened via
`file://` (no server). To keep "double-click index.html" working while
still keeping content in a plain text file, `data/bundle.js` is a
generated file that just does `window.WARDOGS_LINES = [...]` and is
loaded with a normal `<script>` tag (which *is* allowed under `file://`).
`js/lines.js` prefers this bundle when present, and falls back to
`fetch()`-ing `data/announcements.txt` directly if it's absent — which
lets you skip the build step entirely by running a tiny local static
server instead, e.g.:

```bash
npx serve .
# or
python -m http.server 8000
# or, no installs needed on Windows:
powershell -ExecutionPolicy Bypass -File dev-server.ps1
```

Either way, **`announcements.txt` is always the source of truth** — you
never hand-edit `bundle.js`.

## Anti-repeat system

Each shown announcement is remembered (its exact text) against the last N
shown (Settings > Recent history size, default 30, persisted in
`localStorage`). Picking a line already in that recent list triggers a
reroll (up to 50 attempts) before falling back to allowing the repeat —
so a short list, or a history size close to the list length, can never
hang; it just starts allowing repeats once the whole list has cycled
through.

## Team picker

A colored TEAM: GREEN / BLUE / RED badge sits above the announcement text
and rerolls at random every time a new announcement is shown — on
rotation, on NEXT, and when opening a share link. It's an independent
coin-flip each time (no anti-repeat), purely client-side.

## Sharing a specific announcement

Hit **SHARE** below the controls to copy a link to whatever announcement
is currently on screen. The link just carries the exact line as a query
param (`?say=...`) — no server, no database, no lookup involved, so it
never breaks even if you later edit or reorder `announcements.txt`.

Opening a share link shows that exact line immediately, paused (so it
won't get replaced by the timer), with the link stripped from the address
bar right away. Hit **RESUME** to fold back into the normal rotation, or
**NEXT** to jump straight to a fresh random one.

## Debug / diagnostics

Startup logs how many lines loaded, and warns (without crashing) about
any blank or duplicate lines in `announcements.txt`. Open the browser
console and run:

```js
testAntiRepeat(1000)
```

to simulate 1,000 draws against the configured history size and report
how many unique lines got shown and how often an immediate repeat
happened — useful for sanity-checking behavior with a short list, or
confirming a large curated list cycles well.

## Settings

Gear icon (top right) opens a panel for: rotation interval and recent
history size. Both persist to `localStorage`; "Reset to Defaults" clears
them back to the shipped defaults (4 minutes, history of 30).
